### Publication and PDF policy

- The CSV links **publisher-hosted papers**; an arXiv copy is **not** counted as the publication venue.
- A publisher PDF link is **not evidence of a PDF committed to this Git repository**.
- No binary publisher PDFs have been uploaded in this update. Use the links to read/download and use [the optional fetch helper](fetch_official_pdfs.py) to build a *local* collection. Only redistribute full-text PDFs if their specific license permits it; permission and attribution conditions vary across proceedings.
- Papers in Findings, workshops, journals and other secondary sources can remain in the original [69-study collection](../README.md) as context, but are **not part of this strict core**.
- Conference acceptance does not establish quality on its own; run the [full-text screening protocol](../research/main-conference-prisma-protocol.md) before treating a candidate as finally included.
